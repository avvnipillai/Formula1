# 🏎️ Lap Time Prediction – 2024 British Grand Prix

## 📌 Overview

This project predicts **Formula 1 lap times** using statistical methods based on data from the **2024 British Grand Prix at Silverstone**.

We use:

* Linear Regression → for prediction
* ElasticNet → for removing multicollinearity
* ANOVA → to test differences between drivers/teams
* Tukey Test → for pairwise comparison

---

## 🎯 Objective

* Predict lap times using race data
* Identify key factors affecting performance
* Compare drivers and teams statistically

---

## 📊 Dataset

The dataset includes:

* Driver
* Grid Group
* Race Phase
* Lap Number
* Tire Type
* Track Condition
* Lap Time (target variable)

---

## ⚙️ Methods

### 1. Linear Regression

Used to predict lap time based on features like lap number and track condition.

### 2. ANOVA

Checks if lap times differ significantly between drivers or teams.

### 3. Tukey Test

Finds which specific drivers/teams have different performance.


## 📉 Output

* Predicted lap times
* Statistical test results
* Performance comparison between drivers
